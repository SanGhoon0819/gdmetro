# GD메트로타워 공식 평면도 반영 · 2026-10-24

사용자 지시로 아파트갤러리와 별도 GD메트로 홈페이지에 공식 평면도를 반영했다.

- 공식 출처: https://www.gdmetro.com/grand/type/type_info.asp
- 24A~D, 28A~F, 29A~B, 45A~B, 46A~B, 53A~D 총 20개 타입. 사용자 제공 분양광고 공급면적표와 전용면적·공급실수를 대조해 B동 770실 확인.
- 24D 실제 전용면적은 25.0149㎡이며 타입명 24D는 공식 표기 그대로 유지.
- 원본 PC·모바일 이미지 40개를 보존하고 asset-provenance.csv에 출처·크기·해시를 기록.
- 세대타입 준비중 화면을 면적군/타입 선택·키보드 전환·원본 확대 화면으로 교체.
- 메인/사업개요/세대타입에 중도금 최대 60% 무이자와 적용기간, 납부비율, 2031년 3월 입주 예정 및 변경 가능 안내 추가.
- 기존 연락처·관심고객 접수 설정·도메인 설정 유지. 별도 홈페이지는 도메인 연결 전 미리보기 상태를 유지한다.

검증: 기존 테스트 8개 통과. 브라우저에서 두 사이트 모두 20개 타입 전환, 원본 확대 확인. 모바일 폭에서 가로 넘침 없음 및 모바일 이미지 선택 확인. 아파트갤러리의 다른 13개 현장 데이터 변경 없음.

관리 시트: 현장마스터 11행, 소구점_입력 9행, 상세관리_공통 527·544행 및 686~705행(고정ID plan24a~plan53d), 자주묻는질문 96~99행.
